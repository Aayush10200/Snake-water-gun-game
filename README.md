# Snake-water-gun-game
🐍 Snake, Water, Gun Game

A simple Snake, Water, Gun game built using Python.
This is a beginner-friendly project created to practice basic Python programming concepts.

🎮 About the Game

Snake, Water, Gun is a game similar to Rock, Paper, Scissors.

The rules are:

🐍 Snake beats 💧 Water

💧 Water beats 🔫 Gun

🔫 Gun beats 🐍 Snake

If both the player and computer choose the same option, the game is a draw.

The player chooses an option, and the computer randomly selects one. The winner is decided according to the rules above.

✨ Features

🎯 Player vs Computer

🤖 Computer makes a random choice

🏆 Automatically determines the winner

🔄 Simple and interactive gameplay
